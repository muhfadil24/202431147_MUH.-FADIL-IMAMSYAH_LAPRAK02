a. Mengapa menggunakan CSS dan JavaScript?

CSS digunakan untuk mengatur tampilan agar konsisten dan menarik. JavaScript menambah interaktivitas dan logika dinamis pada halaman web.

b. Konsep dan tujuan Responsive Web Design (RWD)

RWD membuat tampilan web menyesuaikan ukuran layar, sehingga nyaman diakses dari desktop, tablet, maupun smartphone.

c. Kombinasi CSS, JavaScript, dan RWD

CSS mengatur gaya, RWD memastikan adaptasi di berbagai perangkat, dan JavaScript menambahkan interaktivitas. Ketiganya saling melengkapi untuk pengalaman pengguna yang optimal.
